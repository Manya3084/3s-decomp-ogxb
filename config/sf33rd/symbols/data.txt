// "hand" rows were read off the bodies in hand-ported src/ files. "map" rows

// builds, the debug body's data references and the XBE body's absolute
// operands are compared, and a symbol's XBE base is the one that makes every
// function's addresses land on offsets that function used. On the hand rows,
// 264 of 270 comparable map placements agreed. A map row that conflicts with
// a hand row is left out. size is the PS2 debug size; the Xbox layout can
